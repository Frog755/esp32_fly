# code/flight_v9 —— 耀坤 K1.0 正式飞控（干跑版）

> ⚠️ 当前固件 `FLIGHT_MOTOR_OUTPUT=0`：**电机驱动没有编译进固件**，上电即锁低 4 个电机引脚，任何操作都不会让电机转。
> 控制器照常计算，算出的电机指令只在串口和手机网页上显示。

## 飞行流程

```
解锁（电压 ≥3.6 V、倾角 <20°、静止、手机链路在线）
  ├─ 松手 / 抛出（失重 40 ms）→ 回正 ─┐
  └─ 按住「起飞」→ 升到 +0.8 m ───────┴→ 稳定 0.25 s → 悬停 5 s → 以 0.35 m/s 降落 → 触地 0.3 s → 停桨
```
转入降落：悬停满 5 s、按「降落」、低电压、回正 4 s 未稳、起飞 6 s 未到高度、通电 40 s、**手机链路丢失（心跳超时 0.6 s）**。
停桨：触地、撞击 >6 g、传感器失效、降落 20 s 未触地、**急停**。解锁后 20 s 没出手、或解锁中链路丢失 → 自动上锁。

## 手机控制

1. 板子上电，等约 8 秒（开机要**静止 2 秒**标定陀螺）。
2. 手机连 Wi-Fi **`YK-FLY-DC55`**，密码 **`ykfly2026`**（名字后 4 位是板子 MAC，每块板子不同；串口开机日志 `BOOT wifi_ap` 行会打印）。
   手机提示"此网络无法访问互联网"时选**保持连接**；关掉"WLAN+ / 智能切换 / 自动切换移动数据"之类的功能。
3. 浏览器打开 **http://192.168.4.1**。
4. 页面按钮：**按住解锁**（0.6 s）、**按住起飞**（0.6 s）、**降落**（点一下）、**急停**（按下立即生效）。
   页面每 0.1 s 发一次心跳；锁屏、切到别的应用、走出信号范围 → 心跳断 → 飞行中自动降落、解锁中自动上锁。
   飞行中切到后台时页面还会先主动发一次"降落"。手机屏幕超时请调长。

## 串口（桌面调试）

`arm` / `takeoff`（= `go`）/ `land` / `disarm` / `status` / `hb`（串口心跳）；空格或 `k` = 立即 disarm。
解锁需要链路：串口测试时要每 0.1 s 发一次 `hb`（`dryrun.sh` 已自动发送）。

## 脚本（都在本目录，`./xxx.sh` 运行，按提示操作）

| 脚本 | 用途 |
|---|---|
| `dryrun.sh` | 干跑检查 8 步：平放 / 右侧朝下 / 机头朝下 / 左侧朝下 / 逆时针自转 / 倒扣 / 翻回 / 安全逻辑（含起飞超时降落、急停、链路丢失）；`--only=1,8` 只跑指定步 |
| `level_trim.sh` | 测 IMU 安装倾斜（平面上测 → 原地转 180° → 转回复测），生成 `level_trim.h` 后需重新编译烧录 |
| `test/run_host_test.sh` | 电脑上的单测：控制器方向、飞行状态机、竖直滤波、心跳超时（62 项）+ 手机网页脚本（15 项） |
| `timing_probe.py` | 每 10 s 统计一次 1 kHz 控制循环的迟到情况 |

## 编译

```bash
source ~/.espressif/tools/activate_idf_v6.1.sh; idf.py build; idf.py -p /dev/ttyACM0 flash
```
重新标定（`../sensor_test/calib.sh`、`level_trim.sh`）后都要重新编译烧录。
电机驱动版只允许做编译检查：`idf.py -B build_mc -DFLIGHT_MOTOR_OUTPUT=1 build`（**不要烧录**，真转电机前先和用户确认）。
