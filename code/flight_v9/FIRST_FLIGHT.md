# 首飞方案与检查清单（Stage 33，系留首飞）

> 依据：固件核心软件在环仿真（SIL）+ 装桨振动检查 3 次 + 录音测转速。**仿真结果，还没真飞过。**
> 第一次飞完用黑匣子（`first_flight.sh` 自动分析）核对悬停占空比、推力修正系数、顶上限占比，再决定下一步。
> 历史：Stage 29 的"油门上限 0.95"基于错误的推力模型（真机推力约为模型的 3.6 倍），已作废。

## 1. 推力换算与油门上限

| 项 | 值 | 来源 |
|---|---|---|
| 真机悬停占空比（满电静止电压 ~4.17 V 时） | 估计 0.41~0.47，固件按 **0.42** | 30% 录音转速 ~209 转/秒（推力约为重量 48%）+ "40% 快离地" |
| 推力换算 | 真实占空比 = **0.555** × c_k × 控制器指令 | `flight_core.h` FC_DUTY_SCALE |
| 空中推力在线修正 c_k | 0.75~1.30，离地后约 1.5 s 收敛 | 比力 / 以为的推力；贴地不修正 |
| 控制用电压 | 电机转之前的静止读数，飞行中保持 | 一转读数就掉 0.8 V（原因未明） |
| **首飞油门上限 `FLIGHT_U_MAX`** | **0.70**（真实占空比） | 正常最多 0.555 × 1.30 = 0.72，只截最极端情况 |

SIL（`RL/results/stage32/sweep_hover_umax070.json`，每格 128 架；"掉 0.8 V 是读数偏差 / 读数偏差 + 高油门推力变平 / 真实压降"三种情形取最差，成功% / 坠地%）：

| 真机悬停占空比 | 0.36 | 0.42 | 0.46 | 0.48 | 0.52 |
|---|---|---|---|---|---|
| 地面起飞（**首飞用这个**） | 100/0 | 100/0 | 100/0 | 99/0 | 0/0（起不来 → 超时降落） |
| 起飞，传感器噪声偏大 | 100/0 | 100/0 | 96/4 | 62/5 | 1/9 |
| 手持松手 | 100/0 | 100/0 | 100/0 | 72/0 | 0/0 |

- 0.48 以上的问题只出在"真实压降"情形：电压真掉 0.8 V 时推力上限不够。若掉压只是读数偏差，0.48 仍 100%、0.52 地面起飞 100%。
- 推力不够时的表现是"起不来"（6 s 起飞超时 → 自动降落 → 停桨），不会冲高。
- 仿真里起飞最高点：中位 0.9 m，最大约 1.2 m（悲观噪声 1.5 m）。

## 2. 首飞前检查清单（`first_flight.sh` 会逐项问，任何一项答"否"就退出）

**电源（最重要）**
- [ ] 电池充满，**静止 ≥ 4.10 V**（手机网页上看）。
- [ ] **电池焊点 / 插头检查过**：目视、轻掰电池线，确认不松、不虚焊。已知现象：插拔 USB 有时会让飞机断电；电机一转电压读数就掉 ~0.8 V。
      飞行时 USB 必须拔掉，如果电池那一路接触不良，飞到一半可能断电摔下来（系留限制了摔落高度 < 1.5 m）。
- [ ] 脚本会让你先拔 USB 再起飞：拔完看手机网页是否还连着；**网页断了又重连 = 拔 USB 时断电了，不要飞**。

**飞机**
- [ ] 4 个桨方向对：俯视 **左前 / 右后 顺时针，右前 / 左后 逆时针**；拧紧、没裂纹。
- [ ] 机体螺丝、电池固定牢靠，没有松动的线靠近桨。

**系留**
- [ ] 细钓鱼线或风筝线（轻、不缠桨），**1.5 ~ 2 m**，系在机身**底部中心**（重心正下方），另一端拴 ≥ 1 kg 重物、放在起飞点正下方。
- [ ] 线理顺放在地上、离桨远；正常飞行（≤ 1.2 m）线不受力，只在冲高 / 飘走时拉住。

**场地**
- [ ] 起飞点**半径 3 m 内没有人和东西**（没有光流，悬停会水平漂移，仿真约 10 秒 2~3 m；系留会拉住）。
- [ ] 平整硬地面（触地判定靠"推力降下来且不再下降"）；无风。
- [ ] 电脑放在 1~2 m 外、不在飞机可能飞到的地方（录音测悬停转速）。

**操作者**
- [ ] 手机连热点 `YK-FLY-xxxx`，打开 http://192.168.4.1，锁屏时间调长。
- [ ] 站在 2 m 外，手指能随时按到「急停」。

## 3. 飞行步骤

1. **系留起飞（这次）**：`./first_flight.sh` → 烧首飞版（上限 70%）→ 拔 USB → 手机 解锁 → 起飞（+0.8 m）→ 悬停 5 s → 自动降落 → 触地停桨 →
   插回 USB 读黑匣子。看：是否进入悬停、推力修正系数 c_k（离 1 多远）、顶上限占比、姿态、漂移。
2. 根据 c_k 修正换算（`FC_HOVER_DUTY = 0.42 × c_k`），再飞 1~2 次确认 c_k ≈ 1。
3. 之后再考虑：手持水平松手 → 抛出（各自先系留）。

## 4. 随时急停的条件
- 起飞后明显倾斜、打转、冲高超过 1.5 m、飘向人或东西 → 立刻按「急停」（拴着绳，摔落 < 1.5 m）。
- 手机网页断开 → 飞机会自己降落（0.6 s 心跳超时）；不要追着飞机跑去重连。
- 落地后先别拔电池，插 USB 读黑匣子；任何一次落地后静止电压 < 3.8 V → 换电池。
