# 首飞方案与检查清单（Stage 29）

> ⛔ **第 1 节油门上限结论作废（2026-11-24 Stage 30）**：装桨 40% 时飞机已轻微离地，真机推力远大于仿真模型（仿真 40% 只有重力 ~20%）。
> 必须先做推力标定、修正推力模型后重新扫描。检查清单（第 2~4 节）仍有效。

> 依据：`RL/results/stage29/sweep_umax.json`（固件核心软件在环仿真，油门上限加在与固件 `motor_out_write()` 相同的位置）。
> 仿真结果，**未起飞验证**。真机悬停油门可能和仿真不同，首次系留飞行后用黑匣子核对再调。

## 1. 油门上限：首飞用 `FLIGHT_U_MAX = 0.95`

推力 ∝ 油门²：上限 0.95 = 最大推力的 90%，0.90 = 81%，0.85 = 72%。仿真里满电悬停峰值指令约 0.84、半电约 0.94（电池压降后）。

| 上限 | 地面起飞 满电 | 起飞 满电 + 悲观噪声 | 起飞 **半电** | 手持松手 | 任意姿态抛出 |
|---|---|---|---|---|---|
| 0.80 | 0%（飞不起来） | 0% | 0% | 0% | 0% |
| 0.85 | 100%（顶上限 11%） | **46%** | 0%（飞不起来） | 100% | 23% |
| 0.90 | 100% | 100%（顶上限 8%） | 100%，但 **72% 时间顶上限** | 100% | 78% |
| **0.95** | 100% | 100%（1%） | 100%（10%） | 100% | 91% |
| 1.00 | 100% | 100% | 100%（2%） | 100% | 96% |

（256 架 / 格；"顶上限"= 起飞 + 悬停期间至少一个电机被截断的时间占比 P90）

结论：
- 这架飞机推重比不高（满电约 1.7、额定 3.7 V 约 1.4），**上限稍低就没有控制余量**：0.85 时悲观噪声下一半坠地，0.90 时电池稍低就大部分时间顶在上限上。
- 上限对"失控时飞多高"几乎没有约束作用（0.95 时最大推力仍有重力的 1.4~1.6 倍），**安全靠系留绳 + 自动降落 + 手机急停**，上限只是挡住满油门的最后 10%。
- 所以首飞用 0.95：起飞 / 松手和不限上限一样，抛出略降（96% → 91%，首飞不做抛出）。
- **0.95 和 1.00 差别很小，用 1.00 也合理**（仿真里 1.00 在每一项都 ≥ 0.95）。留 5% 的理由都不强：
  满油门时 4 路总电流最大（约 10 A），电池压降和电机 EMI 都最大，截掉最上面一段能稍微降低芯片欠压 / 复位的风险；
  控制器方向万一算反、把某几个电机推到底时，冲力小 10%。首次系留飞行后看黑匣子的"顶上限占比"，基本没顶到就改 1.00。
- 仿真里起飞最高点 P90 1.07 m、悲观 1.35 m、最大 1.51 m（目标 +0.8 m，有过冲和气压漂移）。

## 2. 首飞前检查清单

**硬件**
- [ ] 电池充满，**静止电压 ≥ 4.10 V**（手机网页上看）；半电时余量明显变小（见上表）。
- [ ] 4 个桨装对方向：M4 左前 / M2 右后 **顺时针**，M1 右前 / M3 左后 **逆时针**（俯视）；桨拧紧、无裂纹。
- [ ] 机体螺丝、电池固定牢靠，没有松动的线靠近桨。
- [ ] **USB 拔掉**（电机 EMI 会让 USB 复位 → 芯片复位）。

**系留**
- [ ] 细钓鱼线或风筝线（轻、不缠桨），**1.5 ~ 2 m**，一端系在机身**底部中心**（重心正下方，拉力不产生翻转力矩），另一端系在地面重物上（≥ 1 kg），重物放在起飞点正下方。
- [ ] 线在起飞前理顺放在地上，离桨远；线长保证飞到 1.5 m 也不会绷紧（正常飞行不受力，只在飘走 / 冲高时拉住）。

**场地**
- [ ] 室内空地或无风室外，起飞点周围 **半径 ≥ 3 m 没有人和障碍物**（无光流，悬停会水平漂约 2 m / 10 s）。
- [ ] 平整硬地面（触地判定依赖"推力降下来且不再下降"）。
- [ ] 操作者站在 2 m 外，手机连热点 `YK-FLY-xxxx`，网页亮屏、锁屏时间调长。

**固件**
- [ ] 烧录飞行版：`-DFLIGHT_MOTOR_OUTPUT=1 -DFLIGHT_U_MAX=0.95`（由用户运行脚本烧录，见下一阶段）。
- [ ] 网页顶部红条显示「电机会真转（油门上限 95%）」。

## 3. 飞行步骤（每一步过了才进下一步）

1. **装桨振动检查（不离地，Stage 30，`./vib_check.sh`）**：上限 **0.40**。仿真里 0.50 推力约为重力 45%，但单电机推力 0.27 N 是估计值、
   没台架标定：真机推力若是仿真的 2 倍，0.50 会到 ~90%（加贴地效应可能离地），0.40 仍 < 60%。装桨、系留，**拔 USB**，手机 解锁 → 起飞，
   约 6 s 起飞超时 → 自动降落 → 停桨；插回 USB 读黑匣子：飞机贴地不动，"电机转时 − 转之前"的姿态估计差就是振动误差
   （< 3° 正常，3~8° 先处理振动，> 8° 不能飞），另看门控 k、振动、陀螺抖动。
2. **系留起飞**：上限 0.95，手机 解锁 → 起飞（+0.8 m）→ 悬停 5 s → 自动降落 → 触地停桨。异常随时按「急停」。
3. 落地后**先别拔电池**，插 USB 运行 `./bb_read.sh` 读黑匣子：悬停实际指令、顶上限占比、振动、漂移。
4. 之后再考虑手持水平松手 → 抛出。

## 4. 随时停下的条件
- 起飞后明显倾斜、打转、冲高超过 1.5 m → 立刻按「急停」（系留绳兜底，摔落高度 < 1.5 m）。
- 手机网页断开 → 飞机会自己降落（0.6 s 心跳超时）；不要追着飞机跑去重连。
- 任何一次落地后电压 < 3.7 V → 换电池。
