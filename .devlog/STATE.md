## 核心认知
1. v8 剩余坠毁病因 = 偏航自旋 + 电机滞后；**自旋超前补偿 T_DIR=0.035s** 单项坠毁 36 → 2 架。
2. **噪声影响几乎全部来自姿态估计误差**；陀螺噪声、位置速度噪声零影响（T_DIR 对陀螺噪声免疫）。
   v9 耐受姿态固定偏置 ≤10°、白噪 ≤8°（≥98.6%）。
3. **姿态估计器选型**：
   - 普通 Mahony（Kp=2）：翻转时加速度计比力沿机体 z 轴、不指向上方 → 估计被带偏 18°~30°，v9 降到 88.6%；
   - 纯陀螺积分：短时准（5s 内 99.6%），长时漂（悲观零偏 10s 误差 30°+，v9 96.0%）；
   - **门控 Mahony**：比力模长偏离 1g >15% 或 |ω| 在 1→3 rad/s 时修正权重降到 0 → 翻转靠陀螺、悬停用加速度计拉回漂移 → 99.6%。**Kp≈2，Kp=5 反而变差**。
4. 陀螺量程：单轴 |ω| 最大 25.9 rad/s，未触及 MPU6500 ±2000°/s（34.9 rad/s）。

## 已知局限
- 回正 / 悬停仅仿真，电机未测、未起飞；全部满电开局（低电量按用户要求未测）。
- IMU 假设装在机体中心，未模拟偏心离心加速度；振动按白噪声，真实振动集中在电机频率、可能混叠。
- 垂直通道气压计/加速度计融合仍用真实姿态投影。
- 门控阈值（15%、1~3 rad/s）、T_DIR 依赖电机响应时间，均需真机实测标定。
- 含偏航完全静止 P90 0.99 → 1.31s（推力优先给升力），可用 `YAW_RES` 换回偏航余量。

## 电机映射（2026-11-23 定论，不再做电机测试）
来源：2026-11-17 耀坤 bench_test 拆桨实测（轴贴纸旗、6% / 6 s 慢转，用户俯视确认）：
M4 左前 GPIO16 顺时针、M1 右前 GPIO6 逆时针、M2 右后 GPIO5 顺时针、M3 左后 GPIO15 逆时针；点动顺序 M4→M1→M2→M3 与位置一致。
仿真 rotor_pos / rotor_dir（机体 FLU）：out_u[0]=FR(+x,−y) 逆时针、[1]=BR 顺、[2]=BL 逆、[3]=FL 顺 —— 位置与转向逐一吻合，因此：
**out_u[0]→M1/GPIO6，out_u[1]→M2/GPIO5，out_u[2]→M3/GPIO15，out_u[3]→M4/GPIO16**，偏航无需额外取反
（耀坤固件 kYawTorqueSign=−1 是因为它的默认混控假设左前逆时针，与实物相反；10-23 实飞配平佐证了实物转向）。
注：耀坤 docs/mpc/部署评估.md 的"候选 A / B"把 sim0 当成左前/右后，两者都不对，以此处为准。前提：标定时的"机头"= M4 与 M1 之间。
PWM：LEDC 20 kHz、10 bit，占空比 = u×1023，高电平导通（AO3416 低边）。EMI：12% 油门会触发 ESP_RST_USB（USB 总线复位→芯片复位），6% 不会；12% 时电池 4.15→4.05 V。
