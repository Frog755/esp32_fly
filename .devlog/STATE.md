# 项目实时状态看板 (STATE.md)

> 更新：2026-11-22 ｜ 阶段：Stage 17 完成（v9 低掉高快速回正，仿真 99.6%）→ 下一步：噪声/低电量复测 → C 移植 → 真机部署

## 目标与达成
- 目标：减少回正阶段的高度损失，并缩短回正耗时（用户需求：v8 回正时仍会掉高好几米）。
- **达成结果（v9，8 个种子 × 512 通道均值，含 5 个留出种子）**：
  - **成功率 94.3% → 99.6%**，坠毁 29.0 → **1.9** 架/512（留出种子同为 99.6%）；
  - **掉高 中位 1.17 → 0.87m，P90 2.54 → 1.57m**，深倒扣 (≥135°) 中位 2.04 → **1.26m**；
  - **倾斜翻正 中位 0.274 → 0.225s，P90 0.463 → 0.316s**；
  - **进入稳定悬停 中位 2.25 → 1.35s，P90 3.31 → 2.08s**；
  - 官方 512 判据 seed=2024：99.6% (510/512)，深倒扣 98.8%，高转速 98.6%，中位下坠余量 +2.37m。

## 核心认知
1. **v8 剩余坠毁的病因 = 偏航自旋 + 电机滞后**：初始 |ωz| 11~19 rad/s，电机滞后 30~45ms 内力矩方向被转偏 ~30° → 螺旋乱甩。
   **自旋超前补偿 `T_DIR=0.035s`** 单项把坠毁从 36 架降到 2 架；最优值落在电机时间常数之间（有物理解释，非巧合）。
2. 其余贡献（单独关掉后的坠毁数）：约简姿态测地线 bang-bang 14、电压感知推力 11、力矩优先分配 6。
3. 垂直通道增益（KV_Z 9.0 / KZ_REF 3.0 / VZ_UP 1.8）不影响成功率，只缩短掉高与稳悬耗时。
4. 模型失配下 v9 全部优于 v8；最弱项电机滞后 ×1.4：96.0% vs 87.4%。

## 已知局限
- **仅仿真**：理想姿态/角速度/位置，无传感器噪声；陀螺噪声直接影响 T_DIR 补偿角。
- 全部满电开局，电压感知收益在低电量时缩小。
- 含偏航完全静止 P90 0.99 → 1.31s（推力优先给升力），可用 `YAW_RES` 换回偏航余量。
- T_DIR 依赖电机响应时间，真机需实测后设定。
