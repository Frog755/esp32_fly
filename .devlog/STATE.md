## 目标与达成
- 目标：深入“维度3”（SO(3) 测地线翻转与动力学优化），攻克大角度翻转后残余动能过冲导致的升力损失与低空触地。
- **达成结果（v8，512 通道，seed=2024）**：
  - **总成功率 94.5% (484/512)**，4 随机种子均值 **94.6%**（2024: 94.5% / 42: 93.4% / 100: 95.5% / 2026: 95.1%）；
  - **坠毁 39 → 27 架**（-12 架，坠毁率降 30.8%）；
  - **深倒扣带 (≥135°) 84.7% (72/85)**，历史最高；
  - **高转速带 (ω≥14 rad/s) 85.5% (124/145)**；
  - **漂移 >3m 失控率 0.8%**（仅 4 架）；
  - **中位水平漂移 0.055m，平均水平漂移 0.186m，最终高度误差 0.083m**；
  - **中位下坠安全余量 +2.03m**。

## 核心战果与关键认知
1. **欧拉陀螺力矩前馈解耦**：|ω|≥14 rad/s 时交叉力矩 ω×(Iω) 达 0.0096 N·m，占整机极限电机力矩 43%，引起锥形进动；v8 加入前馈项 τ = τ_cmd + ω×(Iω) 消除。
2. **翻转出关动能过冲溯源与临界过阻尼刹车 (`vec_expert8_env.py`)**：
   - 翻转交接时残余 15~25 rad/s 角速度，原欠阻尼姿态环在推力饱和下刹不住，反向过冲到 51°，垂直推力损失 37% 持续 200ms，低空以 1mm 误差触地坠毁。
   - 姿态环重构为临界过阻尼（ζ = 1.13, ωn = 20.9 rad/s，Kp=0.025, Kd=0.0027），回正后零过冲锁平，单项救回 12 架。
3. **抗积分饱和高度门控**：仅在 |z-2.5| < 0.35m 时积分，消除 4m 冲顶过冲。
4. **ESP32-S3 C 固件按位对齐 (`recovery_expert8.h`)**：经 `verify_expert8_c_equivalence.py` 校验，C 与 Python 最大单电机 PWM 误差 **1.29×10⁻⁶**，单步耗时 < 0.65μs，0 堆内存。
