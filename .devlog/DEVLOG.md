## [2026-10-30] 奖励函数迭代 v2 → v5（四轮消融实验）

- **背景/动机**: v2 基线训练曲线健康（reward 涨 10 倍、回合长度接近上限）但真实成功率仅 1~3%，需要定位并修复。
- **核心操作与结果**:
  1. **v2 诊断**：eval.py 显示 42~61% 回合是 `crash_not_upright`；账本分析发现"躺平 -2.8/步"优于"翻转 -5.1/步"，策略理性选择躺平。
  2. **v3**：`r_up` 改为 `-3*(1-up_z)`；`r_rate` 按 `up_z` 三档（0.003/0.01/0.03，全负）；`r_vz` 从按时间触发改为按姿态触发。
     → 成功率 3%→53%(d=0.3)，**95%CI 不重叠，显著提升**；`crash_not_upright` 42→5。
  3. **v4（负结果）**：`r_vxy` 全局加大 0.2→0.6。→ 成功率反降 8pp；`out_of_bounds` 几乎没降而 `timeout_unstable` 暴涨(13→21)。根因：全局惩罚误伤"翻转必然伴随的水平速度"。
  4. **v5**：`r_vxy` 改为仅 `up_z>0.7` 时生效。→ `out_of_bounds` 从 28~41% 降至 **12~22%**，成功率 53%→59%(d=0.3)，但 CI 重叠故不称"显著"。
- **影响/结果**:
  - 累计成功率提升：d=0.3 从 3%→59%，d=1.0 从 0%→31%。
  - 沉淀方法论：惩罚项必须明确"何时生效"；奖励改动后 reward 绝对值不可跨实验比较；失败分类比总成功率更有信息量。

## 2026-11-09 · 锚定剂量反应 + 三方终评：架构族天花板=PD 的 60%

**锚定剂量实验**: λ=0.5/2/5 各 10M 探针 → λ=5 保持力最好（10M 时 16/64 vs 0.5 的 10/64）；λ=5 全程跑 100M 曲线首次不塌（eval_rew 稳 -560、稳定 9-23/64 震荡，best@20M=23/64），64M 处因磁盘满中断。

**三方终评（256通道同种子，成功=未坠地且稳定≥50步）**: model_2M 60.5% ≈ 锚定λ5-best@20M 59.4% ≈ 纯PD 60.2%。一致性问题分析：锚定与无锚策略在 256 个状态上 151 同成功/100 同失败/仅 5 个分歧——**所有策略本质上都是 PD+ε**，60% 是 PD 结构天花板（失败集中在 135-180°×随机转速 15% 与 ω0>14 40-43%）。

## 2026-11-09 · ω-first 课程：阴性，当前架构族实验矩阵收官

**设计**: P1 刹停特训（倾角≤30°+ω0∈U(10,30) 超训 20M，靶子=ω0>14 带的 43% 成功率）→ P2 标准全球面；评估固定标准任务；锚定 λ=5 沿用。

## 2026-11-11 · Stage 13 突破：三轴 4 维直接打靶求解器打通，3 格困难基准 100% 闭环通过

本次任务全面接手方案①：三轴严格四元数 + 4 电机独立优化。

**三大核心突破**:
1. **模型乐观 2.4m 的物理根因彻底查明**:
   原单轴/简化模型在交接点允许 $v_z = -3.0$ m/s，由于 TWR 仅 1.38（净向上加速度仅 $\approx 2.68$ m/s²），在交接后由 PD 接盘制动下坠需要 $\Delta z = v_z^2 / (2a) \approx 1.5$ m，加上姿态对齐损失合计下坠 2.4m。若交接时未主动抑制下坠速度，交接后必贴地或坠毁。
2. **三轴 4 维直接打靶 (Direct Shooting) 架构**:

**18b · 真实姿态估计器（`att_est_wrap.py` + `eval_att_est.py`）**：

四种模式：truth / gyro（Kp=0）/ plain（固定 Kp）/ gated（gate = 比力模长接近 1g ±15% × |ω| 在 1→3 rad/s 线性降权）。
- 常规噪声（零偏 0.6°/s、加速度计振动 1 m/s²）：纯陀螺 v9 99.6%（误差峰值中位 4.0°）；**普通 Kp=2 v9 88.6% / v8 65.1%（误差峰值 18°~30°，失败主要是 55 架"未稳悬"）**；门控 Kp=2 v9 99.6%（3.5° / 6.2°）。
- 悲观噪声（零偏 2.9°/s、振动 3 m/s²、初始误差 5°）+ 10s 回合：**纯陀螺漂移到 32.7° / 59.3°，v9 降到 96.0%（坠毁 20.6 架）；门控 Kp=2 保持 99.6%**（10.8° / 20.2°）。
- 门控 Kp=5 比 Kp=2 差（v8 93.4→91.3%）：水平机动时比力仍沿机体 z 轴，修正过强会把估计拉向"水平"。
- 陀螺量程：全部测试单轴 |ω| 最大 25.9 rad/s、P99 ≈ 22，未触及 34.9 rad/s（余量 ~26%，前提初始 ω ≤ 20 rad/s）。

**关键认知**：陀螺积分的误差是**漂移**（零偏累积），加速度计的误差是**抖动 + 翻转/失重时方向信息失效**。
翻转那 0.3~0.5s 靠陀螺、回到近悬停用加速度计拉回漂移 —— 门控 Mahony 正是此结构，推荐固件采用，Kp≈2。

**局限 / 待办**：IMU 安装在机体中心（未模拟偏心离心加速度）；振动按白噪声（真实集中在电机频率，存在混叠，需低通）；
垂直通道气压计/加速度计融合仍用真实姿态投影；门控阈值（15%、1~3 rad/s）为经验值，未用实飞数据标定。
下一步：移植 `recovery_expert9.h` + 门控 Mahony C 实现，做 C vs Python 逐位校验。

**资产**：`RL/env/{noise_wrap,att_est_wrap}.py`、`RL/scripts/{eval_noise,eval_noise_att,eval_att_est}.py`、`RL/results/stage18/`。
