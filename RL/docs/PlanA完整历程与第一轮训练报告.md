## 三、Plan A 新配方（Stage 5 基础设施，全部已验证）

### 实机：耀坤 K1.0（`env/yao_kun_params.py`）
- 8520 空心杯×4 + 65mm 桨 + 1S 520mAh 30C + 全重 80g
- 单桨推力 0.27N@3.7V [区间值，待台架标定]，**TWR@3.7V=1.38（边缘）**，悬停油门 0.852
- 满油门压降 0.35V → 推力瞬时损失 18%
- **基座版无位置/速度/高度传感器**（开源页原话）→ 观测只用 IMU+电池电压+气压计

### 向量化物理（`env/quad_sim_vec.py`）
- 与标量引擎轨迹误差 **1.8e-12**（含半隐式积分顺序、电机不对称 spool、电池压降）
- 吞吐：裸仿真 180k quad-steps/s

### 新配方环境（`env/vec_recovery_env.py`）
- 奖励 = -0.1×[3·|rel_pos|² + 3·(1-up_z)² + 0.5·|v|² + 0.01·ω² + 0.02·Δa²]，**含高度项**（9 个旧版本从未有）
- 初始姿态全球面 ±π 均匀；仅超时终止（5s）
- deploy 观测 16 维：gyro(3)+acc(3)+重力方向(3)+v_batt(1)+vz_est(1)+z_est(1)+prev_action(4)
- 互补滤波观测器（加计积分为主 + 气压计 Luenberger 校正，**不对噪声气压计做差分**）：
  稳态 vz 误差 <0.06 m/s，z 误差 <0.1m；油门阶跃后暂态 ~2.3 m/s（~0.5s 收敛）
- 气压计误差模型：σ=0.08m 白噪声 + 偏置随机游走

### 吞吐优化实测
| 配置 | 吞吐 |
|---|---|
| RecurrentPPO(LSTM) 全长 BPTT | **31 steps/s**（训练相占 99.8%，SB3 逐序列 Python 开销） |
| PPO+8帧堆叠+3epoch+256envs | **7,500 steps/s**（140 倍）|
| 结论：MLP+帧堆叠替代 LSTM；40ms 窗口覆盖电机滞后 |

### 训练结论修正记录（诚实归档）
1. "稀疏奖励"标签不准确——奖励每步都有分；真问题是**代理目标错位**（v24 奖励里没有高度项！）
2. PPO 机制纠正：同批数据 10 epoch 复用+clip，跨迭代丢弃无回放池；SAC 差异在回放池
3. 手工补丁 15 项清单见对话记录；每项局部合理、联合最优≠任务目标

## 四、Plan A 第一轮训练结果（本轮）

配置：PPO MlpPolicy + 8帧堆叠，256 envs，n_steps=512，n_epochs=3，gamma=0.999，
ent_coef=0.001，lr=3e-4，全球面初始化，1 亿步，48 分钟（24k steps/s）。

**结果：失败，零学习。**

| 指标 | 全程 |
|---|---|
| eval_rew | -528k → -507k 震荡，无趋势 |
| 稳定≥50步回合 | 0/16（所有 50 次评估） |
| 最长连续稳定 | 0 步（连一步都没稳定过） |

### 尸检诊断（`model_100M.zip` 确定性 rollout）
- **策略输出恒定油门 ≈0.53，区间 [0.48,0.56]**——正立、倒扣、不同高度**输出几乎不变**
- 行为 = 初始化状态附近的原地踏步：油门 0.53 → 推力 28% 自重 → 全程下坠（z 最低 -75m）
- 即：**1 亿步后策略仍停在初始化附近，权重几乎没动**

### 根因分析：梯度抵消（cancellation）
全球面初始化下，约一半回合倒扣开局。对"油门"这一维：
- 倒扣状态：推力朝下，油门↑ → 坠得更快 → 梯度说"油门↓"
- 正立状态：油门↑ → 托住 → 梯度说"油门↑"
- 若策略尚未学会按姿态区分输出（常数输出），两类梯度**互相抵消**，净梯度指向折中常数 ≈0.5
- 要逃逸必须先学会"按姿态切换"——但表示这个切换本身的梯度被抵消项淹没 → 死锁
- 佐证：正立+倒扣 rollouts 输出仅差 0.01（0.53 vs 0.54），姿态条件化完全没建立

### 次要因素
- 5s 回合中约 80% 处于"深坠不可恢复区"（位置代价 ±3 千/步且与动作无关）→ 有效学习样本仅 ~20%
- 位置代价权重 3.0 在深坠时 (30m)² 放大到 2700/步，完全淹没姿态/速度项
- 无 TensorBoard：value_loss/explained_variance/std 未记录（第二轮必须补）
