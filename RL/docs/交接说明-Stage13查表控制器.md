# 交接说明：Stage 13 翻转查表控制器

> 生成日期：2026-11-11　｜　上一阶段产出：v5 规则控制器（83.6%）

## 一、任务与目标

微型四旋翼（耀坤 K1.0，80g，TWR@3.7V=1.38）从**任意空中姿态**回正并稳定悬停 2m+。
当前最好成绩是纯规则控制器 v5（无学习成分），正式判据（512 通道）：
- 总分 **83.6%**
- ω≥14 rad/s 高转速带：**76.0%**
- ≥135° 深倒扣带：**67.4%**

**Stage 13 的思路**：把 v5 的"翻转段"换成离线最优轨迹，部署到 ESP32 上查表执行。
目标 ≥89%，且下坠余量从"贴线"提到 ≥0.3m（余量决定真机能否存活）。

## 二、架构总览

```
任意倒扣态 ─→【翻转段：查表】─→ 交接班姿势 ─→【v5 规则收尾】─→ 稳定悬停
                ↑                                      ↑
        离线 LTO 算出来的最优电机序列           PD 姿态环 + 油门环 + 高度外环
```

离线算表（PC）→ 存表（几十 KB）→ 上机查表（ESP32，微秒级）+ 表外/超时退 v5 兜底。

## 四、当前卡点与下一步

**卡点**：单轴简化模型（两组电机统一油门 + 平均滞后 + 固定电压）不足以建表。

**下一步 = 方案①：三轴严格四元数 + 4 电机独立优化**
1. 初值：单轴解 → mixer 顶点投影 → 4 电机序列（已验证此路径能让三轴求解器 1 秒收敛）
2. 求解器放开 4 电机独立优化，终端 = 交接班姿势
3. 先验证 3 格端到端（含完整仿真），通过后过夜跑 300 格
4. 512 通道正式判据终评

**预注册判据**：总分 ≥89% 且中位余量 ≥0.3m 才算成功；只到 86% → 表价值有限，转真机部署。

## 六、必读的踩坑记录（避免重复）

1. **判据事故 5 次**：up_z_of 轴错误（R00 vs R22）、静态表 auto-reset 污染、训练脚本手工 reset 摧毁 eval、组映射对调、单轴/三轴分组不一致。→ 任何两套实现必须固定状态逐项对拍。
2. **残差 RL 全线判负**：PPO+课程/门控/BC 锚定/语义动作层，全部收敛于基座天花板。唯一有效成分是"锚定防塌"，但无增长生态位。→ RL 不是当前路线。
3. **斜轴力矩受限**：绕(1,1,0)/√2 只有纯 roll 的 71%，(1,1,1)/√3 是 66%，yaw 仅 29%。这是 mixer 像空间的物理限制。
4. **模型乐观 2.4m**：单轴模型说余量 1.9m，实跑贴到 −0.5m。→ 每一格必须全仿真验证。
