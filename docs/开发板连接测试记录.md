## 零、最终配置（已验证可用）

写入 `sdkconfig.defaults`，可复现：

```ini
CONFIG_ESPTOOLPY_FLASHSIZE_16MB=y
CONFIG_ESPTOOLPY_FLASHSIZE="16MB"
CONFIG_ESPTOOLPY_FLASHMODE_QIO=y    # 4 线 Flash，运行时生效
CONFIG_SPIRAM=y
CONFIG_SPIRAM_MODE_OCT=y            # 关键！必须 OCTAL，不是 QUAD
CONFIG_SPIRAM_TYPE_AUTO=y
CONFIG_SPIRAM_SPEED_80M=y
CONFIG_SPIRAM_USE_MALLOC=y
CONFIG_PARTITION_TABLE_SINGLE_APP_LARGE=y
```

**验证结果**：`free_heap` 从 387KB 提升到 **8.37MB**（PSRAM 生效）。

### ⚠️ 最重要的踩坑记录

这颗 PSRAM 是 **AP Memory (AP_3v3) 8MB**，必须用 **Octal 模式**。
误配成 QUAD 会无限崩溃重启：

```
E quad_psram: PSRAM chip is not connected, or wrong PSRAM line mode
E cpu_start: Failed to init external RAM!
abort() was called at PC 0x420028ab on core 0
```

**判断口诀**：esptool 报 `Embedded PSRAM 8MB (AP_3v3)` → 用 OCT；报 `PSRAM64/APS6404` 等 8MB 以下 → 用 QUAD。

## 三、解决的两个问题

### 问题 1：串口权限不足

**症状**：`esptool` 报 `[Errno 13] Permission denied: '/dev/ttyACM0'`

**原因**：账号虽在 `dialout` 组，但当前登录会话是在加入该组之前启动的，进程未继承组权限。

**解决**：写入 udev 规则永久生效：
```bash
echo 'SUBSYSTEM=="tty", ATTRS{idVendor}=="303a", MODE="0666"' | \
  pkexec tee /etc/udev/rules.d/99-esp32.rules
pkexec udevadm control --reload-rules && pkexec udevadm trigger
```

结果：`/dev/ttyACM0` 权限变为 `crw-rw-rw-`，且设备重连后依然保持。

> 注：`sudo` 需要密码而会话非交互，改用 `pkexec` 成功提权。

### 问题 2：USB 反复掉线重连

**症状**：内核日志显示设备以精确 3 秒为周期 `disconnect` → 重新枚举，设备号从 88 一路涨到 120+。且此前存在大量枚举失败（`error -32`、`error -71`、`unable to enumerate`）。

**诊断过程**：换 USB 端口后行为一致，说明不是单一端口接触问题。

**解决**：重新插拔后自行稳定，`Dev=059` 连续保持不再跳变。推测为插拔瞬间接触不良 / 插头未完全到位。

**应对手段**：连接芯片时加 `--no-stub` 参数，不向芯片 RAM 写临时程序，握手更快、对时序容忍度更高，在掉线风险下更容易成功。

## 四、端口说明（澄清）

ESP32-S3 双口开发板常见两种 USB 接口：

| 丝印 | 通路 | Linux 设备名 | 驱动 |
|---|---|---|---|
| USB / USB-OTG | 芯片原生 USB-Serial-JTAG (GPIO19/20) | `/dev/ttyACM*` | `cdc_acm` 免驱 |
| COM / UART | 板载 USB-转串口芯片 (CH343/CP210x) | `/dev/ttyUSB*` | 需 CH34x/CP210x 驱动 |

本次实际连的是 **USB 口**，识别为 `/dev/ttyACM0`。

## 七、已知注意事项

1. **PSRAM 引脚冲突**：本板带 8MB PSRAM，GPIO35/36/37 等引脚被 PSRAM 占用，不可作普通 GPIO 使用。
2. **USB 口做 Console**：使用 `/dev/ttyACM0` 时，`idf.py monitor` 直接可用，无需额外 UART 转接板。
3. **下载模式**：若烧录失败，按住 **BOOT** 键，再按一下 **RST**，松开 BOOT，进入下载模式后重试。
